One letter for the day: Z — zero sleep, zany, zapped. A single character describing a day that ran its writer down to nothing and kept going anyway.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes exactly one character, `Z`, to `output/entry.txt` — the whole entry.
